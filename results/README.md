# Generated results

These files are produced by running `python main.py` from the repository root.

- `metrics.json`: known test parameters, neural posterior estimates, estimated uncertainty, and run configuration.
- `training_history.csv`: training and validation Gaussian NLL for each epoch.
- `training_loss.svg`: training and validation loss plot.
- `posterior_estimate.svg`: approximate marginal posterior curves for mu and log(sigma).
- `training_loss.png` and `posterior_estimate.png`: PNG versions generated by the same run.

The committed metrics and plots were generated by executing the repository's training and inference pipeline with 12,000 simulations, 80 observations per simulation, 35 epochs, and seed 7. Numerical estimates are illustrative results from this run, not a guarantee of accuracy on all datasets.
